External agents are found wherever their vendor installs them, and refused with the code that is true. Every reviewed profile now declares its install locations for macOS, Linux and Windows (the vendor installer directories, the Homebrew prefixes and the vendor app bundles, including Claude.app's bundled CLI as the last macOS location), its vendor install and update commands, and a real `--version` line; `ReviewedAcpAgentProfile` makes all of them required at compile time. Resolution searches PATH, then those locations, so a desktop started from Finder with the bare launchd PATH finds the same CLI a terminal does, and each adapter records whether its CLI came from PATH or a fallback (`executableSource`). A `*` path segment resolves to the newest version directory, and a spawn locates such a CLI again when an app update moved it (`resolveAcpAdapterExecutable`). On Windows an npm `.cmd` or `.bat` shim is never selected, and a refusal names the shim it skipped.

The version probe no longer reports a failed probe as "not installed". `CLI_NOT_FOUND` now means no file was found, and `--version` is not run; a timeout, a signal, a non-zero exit or a permission error is `EXTERNAL_AGENT_UNAVAILABLE`, with a message naming the file, the elapsed time against the budget and the exit. A version line with no `x.y.z` keeps the agent advertised and logs a warning (`onWarning`). The model probe is not started for an agent whose CLI was not found. A refused descriptor now carries a `fixCommand` from its profile for the host's own shell: the install command for `CLI_NOT_FOUND` and the update command for `CLI_TOO_OLD`.
