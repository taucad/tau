---
agent-host: minor
---

One launcher for every placement. `@taucad/agent-host/launcher` exports `createAgentLauncher`, which takes an opaque `ChatStore` from `createNodeChatStore` (`@taucad/agent-host/node`) or `createBrowserChatStore` (`@taucad/agent-host/browser`), a `credential` port that answers a `CredentialState` (`credentialPrincipal` names the funded principal), and serves every client with `serveAgentChannel`. Reading a chat never creates its log or takes its lock; a chat's writer is elected per chat and released once its run is quiescent. An `attach` is a read: when it finds an orphaned run (one no driver holds, a paused external run included) it asks leadership to claim it and answers at once with `takeover: true`, which means only that the claim was asked for. The claim abandons the run with a `RUN_ABANDONED` row once it wins the chat's lock, and writes nothing while another tab leads the chat. In the browser, tabs lead a chat over a Web Lock and a `BroadcastChannel` keyed on the project and chat alone, so a tab on another checkout is answered within one heartbeat, a tab on another build is refused `LEADER_VERSION_MISMATCH`, and a silent leader is replaced (stolen on the provider leg) with its later appends refused. `AgentLauncherOptions.turnPlacement` (new) takes a project's `TurnPlacementPort`: the launcher reconciles the chats whose leases it holds when it opens and on each `leaseHeld` fact. `@taucad/agent-host/channel-client` exports `serveTurnPlacementChannel` and `connectTurnPlacementChannel`, which carry a placement session over a `MessagePort` (`admit` transfers the attempt's tool port; a request the server cannot read is answered `FRAME_UNREADABLE`). `AgentLauncherOptions.admitting` (new) is asked with each `start` and `resume`'s `{ chatId, runId }`; while it answers `false` the launcher refuses them `HOST_CLOSED`, so the sender re-sends to the host that replaces this one, and still serves reads, `attach` and the runs it already drives. A chat with a live run still answers `CHAT_RUN_LIVE`, and a command already applied still answers as it did. `AgentLauncher.admittedRuns()` (new) resolves, once every `start` and `resume` under way has its answer, those that arrive while it waits included, to the runs it admitted by chat, those other tabs forwarded to it included; a refused one, or one whose admission threw, is not among them. A draining host waits for each. In the browser, a follower whose forwarded `start` or `resume` the leader refuses `HOST_CLOSED` because it is draining waits for the chat's next leader and re-sends it there once, or runs it itself when the leader releases the chat; after 10 seconds with neither it answers `HOST_CLOSED`, even while this tab asks for the lock. The wire refuses a `chatId` that is not one storage path segment (one holding `/` or `\`, or `.` or `..`), in every command and read; `@taucad/agent-host/wire` exports that rule as `chatIdSchema`. `createTauAgentHost` takes `onChatQuiescent(chatId, quiescent)`, which a new incarnation calls with its own value at open. `createTauCloudGatewayModelTransport` takes `principal`, the account its funding names. A second concurrent `close()` on an `AgentLauncher` or a `TauAgentHost` waits for the first, and a `close()` after one that failed tries again.

Breaking:

- `@taucad/agent-host/node-launcher` is removed, with `createNodeAgentLauncher`, `NodeAgentLauncher` and `NodeAgentLauncherOptions`. Use `createAgentLauncher` and `AgentLauncher` from `@taucad/agent-host/launcher` with `createNodeChatStore` from `@taucad/agent-host/node`; `serveAgentChannel` and the external-agent types move with them.
- `BrowserChatStoreOptions` names its log as `log: { kind: 'opfs', directory } | { kind: 'provider', fileSystem, durability? }` and takes optional `visibility`, `clock` and `delays`; the page-visibility type is no longer exported.
- `TauAgentHost.assumeLeadership(chatId, epoch)` takes the integer epoch the leader read (the log's highest epoch plus one), not a generation token.
- `TauAgentHost.claim(chatId)` is a new required member: it opens the chat's incarnation and resolves once it serves.
- The `interruptPort` option of `createTauAgentHost` and the `InterruptApprovalPort` type are removed; the run actor records every pause as rows.
