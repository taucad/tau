The plugin says what it does wherever a host or registry lists it, from one source. Both manifests and the development catalog describe it as code-CAD for coding agents in replicad, OpenSCAD, JSCAD, Manifold, PicoVoxel, SMLib, tscircuit, build123d and PicoGK, with GeoSpec tests, screenshots and STEP, STL, 3MF or glTF export, and name what it needs: Node.js 24 and `npm install -g @taucad/cli@beta`. Codex's `longDescription` says the same, its `defaultPrompt` adds an export prompt, both manifests' `keywords` name every kernel and export format, and the npm description names the MCP server launcher and the kernel skills.
