filesystem: minor
---

A desktop import copies a folder or file a person chose on the host, host-side, instead of reading its bytes into the worker and writing them back. The Node fs wire protocol is now version 12. It adds `importSourceList` and `importSourceRead`, which list and preview a chosen source by an opaque grant, and `importCopy`, which copies its files into a root. `importSourceList` takes an `offset` and answers at most 1024 rows with `more`, and `importSourceRead` a `position` and `maximumBytes`. `serveNodeFsProvider` takes `importSource(grant)`, which may be async, and resolves every path inside the grant itself. A grant (`ImportSourceGrant`) carries the chosen root's `dev` and `ino`, which `importSourceIdentity` reads, and a use whose root is a link or another inode is refused. Each segment is walked without following a link, and a file is opened `O_NOFOLLOW` and proved by a second walk against the held descriptor. A path that leaves the source, by `..` or through a link, is refused. A link is listed as one and never followed.

`NodeFsProvider.copyImportFiles` lands each file as a batch write does, filling the temp sibling through the held descriptor: on Linux by `copyFile` from `/proc/self/fd` with `COPYFILE_FICLONE`, elsewhere by a streamed copy. Before the rename it reads the sibling once, in chunks, for its git blob id, SHA-256 and content kind, and the receipt carries those facts. A source above the importer's file limit, no longer a regular file of its listed size, or whose descriptor's identity, size, mtime or ctime changed during the copy, fails with the target untouched.

The importer gains `hostImportSource`, a source adapter over `HostImportSourcePort`. The path policy prunes as it walks, and the limits apply as for any folder. A planned entry is now either a decode `request` or a `host` locator. `ImportStagingPort.copyHost` stages host entries from the facts in their receipts, with no decode and no read-back. `NodeFsProviderClient.copyFromImportGrant`, `NodeFsImportSources` and `WorkspaceFileService.importSources()` reach the host.
