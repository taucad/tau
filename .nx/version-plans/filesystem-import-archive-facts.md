`planImport` takes a `root`: only the files under that folder of a source are imported, as the project root, after the shared top folders a repository archive carries, and the pin records it. A zip entry's name is decoded as UTF-8 when its entry is flagged or carries an Info-ZIP Unicode Path field whose CRC matches, as UTF-8 when it is valid UTF-8, and otherwise as code page 437. The import facts record moves to its own module (`importFactsPath`, `ImportFactsRecord`, `StagedImportEntry`, with `parseImportFacts`, `isStagedImportEntry`, `verifiedImportFacts`, `importFactsSkewMilliseconds` and `importFactsMaximumBytes`), and the commit records when it wrote it (`at`). After the Project Index scans a committed import, its first digest request takes its recorded blob ids and SHA-256 for every file they still describe (same size, last written no later than the record, a record whose mtime agrees with its time, well-formed ids) on a provider whose mtimes are trustworthy, counted as `index.importFacts`, so a digest request for those files reads nothing.
