`planImport` takes a `root`: only the files under that folder of a source are imported, as the project root, relative to the one top folder a repository archive carries (`.` or an empty root is the whole source), and the pin records it. A zip entry's name is decoded as UTF-8 when its entry is flagged or carries an Info-ZIP Unicode Path field whose CRC matches, as UTF-8 when it is valid UTF-8, and otherwise as code page 437. The import facts record moves to its own module (`importFactsPath`, `ImportFactsRecord`, `RecordedImportEntry`, `StagedImportEntry`, with `parseImportFacts`, `isStagedImportEntry`, `verifiedImportFacts`, `importFactsSkewMilliseconds`, `importFactsFreshMilliseconds` and `importFactsMaximumBytes`), and the commit records when it wrote it (`at`) and each file's mtime once placed. After the Project Index scans a committed import, its first digest request takes its recorded blob ids and SHA-256 for every file they still describe (exactly the recorded size and mtime, a record whose mtime agrees with its time and that is at most ten minutes old, well-formed ids), once per record on a provider whose mtimes are trustworthy, counted as `index.importFacts`, so a digest request for those files reads nothing.
