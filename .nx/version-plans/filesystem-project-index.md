`@taucad/filesystem` splits metadata from content (I3): `stat`, `readdirWithStats` and `exists` answer kind, size and mtime on every provider and never read a file, and a stat carries `contentKind`/`lineCount` only when they are already known (`StatContentMetadata`). The head mode is removed with it: `FileStatOptions`, `HeadFileStat`, `supportsHeadListing`, the `{ content: 'head' }` option and `fileStatFromFile` are gone, and `DirectoryStatRow` is no longer generic. Content facts are lazy: rooted views and composed views answer `facts(paths, { lineCount, byteCap, digests })` (`ContentFacts`, `ContentFactsOptions`), measured once and cached by `(size, mtimeMs)`, and writes record them on the way in. The kind comes from a file's first 512 bytes, a binary is never read in full for it, and a text file is read in full only for a requested line count within the per-file `byteCap`, eight files at a time (`measureContentFacts`, `lineCountByteCap`, `factsConcurrency`, `mapConcurrent`). A rooted view's whole read records its facts from the bytes it returns (`ProjectIndexes.recordRead`), and `facts` on a root whose index is not open answers from those reads without opening or scanning it. The Node filesystem wire protocol moves to version 9. `ProviderCapabilities.trustworthyMtime` marks a provider whose modification times may key that cache.

`TreeIndex` is replaced by the persistent Project Index (`ProjectIndex`, `IndexEntry`, `IndexVector`, `IndexMirror`, `reservedIndexPaths`). A root on a persistent provider with a trustworthy mtime keeps its snapshot in `<root>/.tau/index/` (`projectIndexDirectory`, `isReservedIndexPath`; `.tau/index` is a root-only cache row hidden from agents, and `.tau-staging` a reserved control-plane path), written off the request path under the root's Web Lock, taken only when free (`persist()` answers `'busy'` and retries later), and only when its cross-tab vector has seen everything the stored one has. A load is validated by a full head-metadata compare, as is a root after a cross-tab sequence gap, on `compareIndex()`, and on every `pollExternalChanges()`; a scan merges with concurrent mutations instead of being discarded, and facts are trusted only past the 2 s racy-timestamp window (`timestampGranularityMilliseconds`). Rooted views answer `hashFiles` from the index where the provider has no digest call of its own, except on a webaccess root. External-change ingest drops facts about the control plane and the index's own files at any depth. `workerTimings` counts `index.load`, `index.scan`, `index.compare`, `index.facts.bytes` and `view.facts.bytes` in place of `listing.bytes`.

`@taucad/revisions`' capture memo applies the Project Index's racy window. `@taucad/agent-host`'s browser event log stats without the removed head option. `@taucad/host` lists MCP viewer folders through a `ProjectIndex`.
