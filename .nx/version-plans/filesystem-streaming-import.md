filesystem: minor
---

A new `@taucad/filesystem/importer` entry imports a project without the page reading its bytes (charter D12). A source is a zip `Blob` read by range (its central directory, ZIP64 included), a list of `File`s with their paths, a directory handle, the handles of a drop (`handleListImportSource`), or a downloaded archive spooled into a `Blob` against its declared size; `planImport` lists it under the injected path policy, pruning what the project never versions while it walks (and never counting it), skipping symlinks, refusing zip-slip paths and paths one filesystem would merge, and enforcing one limits policy (`importLimits`: 1 GiB archive, 1 GiB expanded, 100 MiB per file, a ratio of 100, a 1 KiB path and 50,000 entries) as it lists and as it decodes, each refusal an `ImportRefusedError` with its reason. `readZipDirectory` reads the directory a window at a time, refuses one larger than its entries can need, a name past the path limit, a ZIP64 value outside its extra field and entries whose ranges overlap, and returns the directory's identity, which a zip's pin carries. `decodeImportEntry` inflates one entry into a buffer of its declared size, checks the zip CRC, and computes its git blob id and SHA-256 in the same pass; `readImportEntry` reads one without hashing, for previews. `stageImport` writes the decoded entries once, in changesets of at most 256 files or 32 MiB under a 64 MiB resident budget, recording each batch in a ledger under `.tau-staging/import-<operation>/`, resumes a staging of the same source after a crash, and stops every decode on a failure or abort. Given the pending project directory, it stages under `tree/` where the provider's rename is a metadata operation (the new `movesInPlace` capability, declared by OPFS and Node) and writes straight into that directory where a rename copies. `commitPendingProjectDirectory` takes a `staging` locator and commits the project by moving the staged files into place, or checking them in place, writes the measured facts to `.tau/import.json` and `tau.json` last, and removes the staging, including on a replay that finds the project already committed. `sweepStagedImports` removes stagings no journal row or live session owns once they are still; `isReservedImportPath` and the journal's file check refuse every spelling of the manifest and identity through the path registry's fold; `WorkspaceFileService.importStaging(scope)` gives the importer its storage root. OPFS no longer sweeps an import's staging as a dead realm's.
