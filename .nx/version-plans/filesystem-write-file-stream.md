Add `writeFileStream(path, stream)` to `FileSystemProvider` and the rooted `privateStore`: one file written from a stream of its bytes, which lands whole or not at all (I1). OPFS stages the chunks through a sync access handle under `.tau-staging/<owner>` and moves the file into place. A picked folder replaces an existing file with the writable stream's swap file on close, and records a new one as an uncommitted create before making it (it reads as empty until the stream ends, and `recoverUncommitted` removes it after a crash), or, with `stageCreates`, stages it as a temporary sibling and moves it into place. `NodeFsProvider` writes its temp sibling, syncs and renames it, verifies the published file by its SHA-256 read back in chunks, and sweeps crashed temp siblings the first time it writes in a directory. Each holds one chunk at a time. A stream that errors leaves the path as it was, nothing staged and no parent it made, and every refusal cancels the source. Memory, IndexedDB and the Node bridge client gather the stream and write once.
