`ProjectHostActor.settled()` waits for close retries after release or completion, so the desktop keeps filesystem authority alive until those revision writes finish.

Add `createProjectHost` and `createProjectHostActor` to `@taucad/host`. `createProjectHost` composes one project's checkouts, revisions, parameter actors, tool registry, ACP port, MCP endpoint and agent launcher, so the daemon and the desktop utility build the same host, and the desktop now offers the parameter tools. `createProjectHostActor` runs one project host's lifecycle: a release names its attach generation and an older one is answered `stale`, a released host drains until its runs end and settle before it closes, and a connect that arrives while it closes is served on a fresh host. `keyedResource` is the one memo for per-key resources and evicts on every close; a resource whose close failed is closed again by the key's next close or `closeAll`, and `closeAll` refuses a caller still awaiting a creation it closed, so it leaves no entry. `AgentServerOptions.launcher` takes the `AgentLauncher` from `@taucad/agent-host/launcher`. The daemon's credential is now a `CredentialState`: it is `unpaired` from the moment the relay rejects the stored credential until pairing returns a new one, so the agent channel refuses a Tau `start` with `HOST_NOT_PAIRED` meanwhile; the pairing token response and the stored credential accept an optional `accountId`, which the funded gateway transport names as its principal. `ProjectHostOptions.turnPlacement` builds the project's `TurnPlacementPort` from its revisions and a `toolRegistryFor(root)`, and the launcher places every turn through it. An ACP turn whose placement names a `root` opens its agent session there. A cancel that reaches an ACP turn before its prompt no longer lets the turn's final record overtake its opening one. `createProjectHostActor` returns a `ProjectHostActor` facade (`start`, `getSnapshot`, `on`, `subscribe`, and `send` of a `ProjectHostCommand`); its internal events cannot be sent. A released host drains only the runs it admitted, bounded by `projectHostDrainBound` (15 minutes), and refuses a new `start` or `resume` `HOST_CLOSED` while it drains. A run counts from the moment its `start` or `resume` arrives, so one still being recorded when the release came is drained too; the drain waits for each such start's answer, follows only those admitted, and looks again until a pass finds no new run. A launcher close that failed is tried again by the host's next close, and a second concurrent `ProjectHost.close()` waits for the first. A parameter actor whose last write does not settle within 10 seconds of its host's close, or settles uncertain, is stopped and reported, and a close tried again passes the stopped actor instead of waiting out the bound once more. One that did not close when its candidate root was released is reported with `console.error` there, since the host's close then passes it. `keyedResource` gains `acquire(key)`, returning `{ value, incarnation }` (`KeyedIncarnation`), and `close(key, incarnation?)` closes by that token, so a caller awaiting creation never receives a value being closed.
