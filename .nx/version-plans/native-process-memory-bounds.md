A native worker's process group is killed synchronously when its host process exits, so a worker inside a long native call no longer outlives its parent. Protocol frames are parsed in linear time however finely stdout is chunked, and an artifact is handed back without a second copy. The Build123d worker bounds its lineage stamps by entry, drops them when a build ends instead of holding every boolean result of the session alive.
