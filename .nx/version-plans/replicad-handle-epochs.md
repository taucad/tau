Replicad builds with `@taulabs/replicad` 1.2.0-beta.2, which builds each operation once and gives every OpenCASCADE value one owner: wrappers adopt what they are given and `cast()` consumes its input. Face outlines and projections no longer leave curve handles behind. The kernel now implements `releaseHandle`: when the runtime drops a build, the shapes it delivered are deleted with the next build, unless that build delivers them again, instead of whenever the garbage collector runs, so the heap stays flat over a long drag. Shapes a model builds at module scope are kept across parameter-only rebuilds. A model that keeps shapes `main` built in module state (a memo keyed by a parameter) and returns one after its build was released no longer fails. The kernel runs that module fresh in the same build and leaves its shapes to the garbage collector. When the module's code changes, the shapes the old instance still holds are deleted. If the fresh run fails the same way (state kept on `globalThis`), the whole worker switches to collector release. The live operation tier keeps at most `computeReuseBytes` estimated bytes across documents (256 MiB by default) besides its entry cap, and evicts its least recently used entries under that pressure. Interface resolution and STEP export no longer leave labels, faces or finders behind. `@taucad/runtime-testing` adds `installHandleLedger` and `summarizeLeaks`, a ledger of live embind handles for leak tests.
