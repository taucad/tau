Use `@taulabs/replicad-opencascadejs` 1.2.1-beta.0. The native package now follows Replicad's version numbers, so 1.2.1-beta.0 is the release after 0.23.0-beta.4. A superseded build whose break arrives after a batch Boolean has finished, but before its `SimplifyResult`, now stops at once instead of simplifying first. On the planetary gear's 15-tool cut that brings the stop from about 137 ms to 44 ms. While nothing aborts, every result is unchanged.
