Run the revision store's CPU work on a supervised compute worker, and open a hosted project's heads without `upload-pack`. `@taucad/revisions` adds `createSupervisedComputeWorker`: one worker spawned on first use, at most four calls in flight, and a heartbeat that takes a worker for dead only after it has been silent while holding calls, so a slow or queued call never kills it. A dead worker, or a `spawn` that throws, fails the calls it held with a typed `ComputeWorkerCrashedError` and is restarted on the next call; past the restart budget calls go to the fallback, except pack indexing, which fails typed. Only a `CorruptBytesError`, marked where the bytes were judged, drops a pack; a crash or a failed allocation never does. `serveComputeWorker` and `createInlineCompute` are exported for the worker side, and the compute contract gains `sha256` and `resolveDelta`. A port given a `catalogue` opens a store that holds no refs from the hosted catalogue: each pack's stored index, then the heads' commits, trees and listed blobs by coalesced Range reads, kept in bounded local packs without indexing, with older history read through while the links last. An `upload-pack` answer is read as it streams and stopped at the 64 MiB pack ceiling (`PackCeilingError`), past which the objects come from the catalogue instead.
