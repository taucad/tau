Name version tags by number. A version's ref is `refs/tags/v<n>` and its free-text name lives in the annotated tag's message and its `Tau-Tag` trailer (now `{ version: 2, id, name, note?, actor? }`), so a name with spaces is a valid version name on both engines. `RevisionTag.number` and `RevisionTag.id` are required: the id is random, minted when a version is made, kept by a rename or a move, and is what `isSameVersion` compares. The name is read from the tag, never the ref. Only an annotated tag with a valid `Tau-Tag` record is a version; any other `refs/tags/v<n>` still holds its number, is never replaced, and an explicit number it holds is refused. An empty name, or a number below 2, is refused before anything is written. Choosing a new version's number and claiming its ref are one guarded step on both engines. `port.tag({ number })` renames that version at the same ref, keeping its id, number, entry, time and actor; `port.tag({ id, number })` moves it; `deleteTag` takes a number and only renumbering uses it. `listTags({ remote })` reads a remote's tags as last fetched. `numberVersions` and `versionNumberFor` are removed; `versionTagRef`, `versionTagName` and `versionNumberOfTag` are exported. Sync leases each version tag on its tracking ref and renumbers a version another device took, counting every held number, finishing an interrupted move and dropping moved refs from the retry. When two devices rename one version, the remote's name wins, on a refused push and on a fetch. `renumberUnpushedVersions` takes `adopt`; `planVersionRenumbering` and `versionTagWrite` take object inputs. The publish draft takes an optional `version`; republishing by number publishes that version's own entry under its stored name. The publish push, row and `published` event name the version's `v<n>` tag at the number its push backed it up at (`versionsRenumbered` now reaches the publish machine). The host's `deleteTag` verb is removed and its `tag` verb takes `number`. `tau version rename` takes `V<n>` or the current name and rewrites the tag in place.
