# Agent Plugin

The Tau plugin, `@taucad/agent-plugin`, gives the coding agent you already use Tau's CAD tools and skills. They evaluate a model, run its GeoSpec tests, return screenshots, export files, arrange the [workbench](./workbench-records) and show the model in the Tau viewer.

It needs Node.js 24 or later, and starts your installed Tau CLI or fetches the matching release on first use:

```bash
npm install -g @taucad/cli@beta
```

## Install

- Claude Code 2.1.292 or later, one step: `claude plugin install tau --marketplace taucad/marketplace`. Older Claude Code: `claude plugin marketplace add taucad/marketplace`, then `claude plugin install tau@taucad`.
- Codex: `codex plugin marketplace add taucad/marketplace`, then `codex plugin add tau@taucad`.
- Claude Desktop: `npm install -g @taucad/agent-plugin@beta`, then add its launcher to `claude_desktop_config.json`.

Name the project folder in the launcher's arguments:

```json
{
  "mcpServers": {
    "tau": {
      "command": "node",
      "args": ["/path/to/node_modules/@taucad/agent-plugin/dist/launch.mjs", "--project", "/path/to/project"]
    }
  }
}
```

Start a new thread or session after installing: the tools appear only there. The plugin is not in the Anthropic or OpenAI plugin directories; install it from the `taucad/marketplace` catalog.

## Check

- Claude Code: `claude plugin list` shows `tau@taucad` enabled.
- Codex: `codex plugin list --marketplace taucad` shows `tau@taucad  installed, enabled`.
- In the project, `node <plugin folder>/dist/doctor.mjs` checks the launcher and CLI.

Troubleshooting, kernel choice and what to tell the user are in the [agent guide](https://taucad.dev/llms.txt).

## What each host shows

`show_model` opens the viewer in the form the host supports:

- Codex desktop: a Tau tab in the thread, Tau in the sidebar, and Open with Tau for files.
- Claude Desktop: an inline card with Add to chat and Open full view.
- Claude Code and Codex CLI: a link to the viewer on `127.0.0.1`; screenshots stay inline.

The tab, full view and browser page add Share, Export and a workbench toggle at the top, and grid, section, measure and fit. Add to chat gives the agent the card's model or a right-clicked part; the browser page copies it instead.

A tab or full view follows each model the agent shows, and the agent can select parts in it. `view_state` reports the model, selected and hidden parts and camera, plus an image with `capture`. `show_model` also opens STEP, STL, 3MF and OBJ files.

The **workbench** lists the parts, parameters, selected part's properties and display switches. A changed parameter is saved to the project and the model redraws; the agent uses the same values through `get_parameters` and `apply_parameter_operation`. Camera and hidden parts are saved too, so Tau reopens the same view.

The viewer makes no network request. Model files reach it through a tool only the page can call, a few megabytes at a time and compressed where that helps, so a large mesh loads without the host dropping the connection. The browser link answers only on your machine, with a session token.

## Printing

Start the agent with `TAU_HOST_MACHINES=true` to use the machines you set up in Tau, from a folder holding a Tau project (`tau.json`). The agent can request a job; nothing starts until you approve it in Tau's Print pane. One Tau app uses your machines at a time, so quit the desktop app first.

## Where files go

Exports and viewed models land in `.tau/artifacts/`, workbench changes in `.tau/workbench/`. Screenshots stay in a temporary folder removed when the server stops.
