The Tau editor is a parametric CAD workspace that runs in the browser at [tau.new](https://tau.new). You describe geometry in code, and the editor renders it as you work.

A project opens as a dockable panel layout:

- **Code editor** — a source editor with language-aware completion.
- **3D viewport** — renders the model, with camera, grid, measurement, and section-view controls.
- **AI chat** — an assistant that reads and edits project files and runs CAD tools directly.
- **Files** — a project file tree with export to standard CAD formats.

Open the [planetary-gear example](https://tau.new/s/builtin~replicad.planetary-gear-system) or the [agent plugin](./agent-plugin). GeoSpec checks geometry, not FEA. Embed from the [runtime quick start](/runtime/getting-started/quick-start).
