# Machine Provider API

Import from `@taucad/runtime/machine`. A provider describes one machine model in a manifest and connects to one machine as a session. The host admits every request against that manifest before the provider sees it; the provider sends, observes and reports.

## Provider definition

`defineMachine` takes a trusted `MachineProviderDefinition` and returns a callable `MachineProviderFactory`. The definition carries identity, `protocolVersion: 2`, an authored `MachineManifestDefinition`, a binding configuration, a submission configuration (the start form), optional settings, `discover` and `connect`. The serializable `MachineProvider` is what every surface reads; `parseMachineProvider` admits only that bounded descriptor. The `/plugin` type `ExpandPluginMachines` lets a composed runtime infer the provider tuple.

`machineManifestOf` turns the authored manifest into the serializable `MachineManifest`: descriptors without their schemas, with the start form filled in. `parseMachineManifest` and `machineManifestSchema` admit a manifest and refuse unknown keys and dangling references. `machineActionDefinitionOf` returns the trusted schema of one installed action or hold for host-side validation.

## Manifest v3

A `MachineManifest` has `version: 3` and these parts:

- `identity`: type id, vendor, model and display name.
- `connection`: `MachineConnectionFacts` for network or serial transport, exclusivity, whether opening resets the controller, and whether identity is authenticated or only claimed.
- `axes` and `components`: each `MachineAxis` the controller moves, and each `MachineComponent` with its kind (`motion`, `spindle`, `tools`, `probe`, `toolhead`, `material-system`, `interlock`, simple kinds by name, or a namespaced vendor kind).
- `processes`: each `MachineProcess`, a `MachineFffProcess`, a `MachineMillingProcess` or a vendor process; `fffProcessOf` and `millingProcessOf` find them.
- `actions`, `holds`, `jobs` and `stop`: what the machine can be asked to do, described below.
- `observations`: each group's freshness budget and whether it is `retained` or `latest` (coalesced, never replayed).
- `qualifications`: each `MachineQualificationProfile`, the hardware or simulation evidence an action names when it is qualified.

## Actions and holds

Declare a standard family with `standardMachineAction` or a provider-owned `<vendor>.<area>.<verb>` action with `defineMachineAction`. Each returns a `MachineActionDefinition`: a `MachineActionDescriptor` plus the schema the host validates parameters with. A provider may narrow a family's schema, never widen it, and may only raise its authority. Every action stays `designed` until the provider names a qualification profile; a person can try it only in Testing mode. `machineJogHold` declares the standard held jog as a `MachineHoldDefinition` with this machine's lease and bound. `machineActionDescriptorOf` strips the schema from either definition.

`jobs` is `unsupported` or `MachineJobFacts`: each accepted container (`MachineAcceptedContainer`, a semantic contract, not a filename extension), `stored` or `streamed` delivery, a `remote` or `at-machine` start, attestations a person makes before a start, and the start's safety floor. `stop` is a `MachineHaltOutcome`: what motion, spindle and heaters do, whether position is kept, and the recovery remedies.

```ts
import { defineConfiguration } from '@taucad/runtime/configuration';
import { machineJogHold, standardMachineAction } from '@taucad/runtime/machine';
import type { MachineManifestDefinition } from '@taucad/runtime/machine';
import { z } from 'zod';

export const manifest: MachineManifestDefinition = {
  version: 3,
  identity: { typeId: 'example.router', vendor: 'Example', model: 'router', displayName: 'Example router' },
  connection: { transport: 'serial', exclusive: true, opening: 'resets-controller', identity: 'claimed' },
  axes: [],
  components: [
    { id: 'light', kind: 'light', label: 'Light' },
    { id: 'gantry', kind: 'motion', label: 'Gantry', axes: [] },
  ],
  processes: [],
  actions: [
    standardMachineAction({
      id: 'switch.set',
      componentId: 'light',
      componentKind: 'light',
      label: 'Light',
      when: ['ready', 'active'],
    }),
  ],
  holds: [machineJogHold({ componentId: 'gantry', lease: 250, bound: 500 })],
  jobs: { type: 'unsupported' },
  stop: { motion: 'halts', spindle: 'stops', heaters: 'none', position: 'kept', recovery: [] },
  observations: [],
  qualifications: [],
};

export const binding = defineConfiguration({
  id: 'example.router.binding',
  version: '1.0.0',
  schema: z.object({ port: z.string() }),
  ui: { version: 1, rjsf: {} },
});
```

## Host services

The provider never receives a general filesystem, socket or secret grant. `discover` receives `MachineDiscoveryInput` and a `MachineDiscoveryRuntime`: `listenDatagrams` admits a user-initiated listener (`MachineDatagramListenInput`) yielding `MachineDatagram` values with peer evidence, and `listSerialPorts` lists each `MachineSerialPort`. It yields `MachineDiscoveryEvent` values.

`connect` receives `MachineConnectInput`, whose `MachineConnectionContext` carries a host-local secret reference and each service's `MachineTransportTrust` (`system` or a pinned digest), and a `MachineConnectionRuntime`. That runtime opens a bounded `MachineNetworkStream` for a `MachineNetworkRequest` or a `MachineSerialRequest`, streams an immutable `MachineArtifactReference` in chunks through `MachineArtifactReadInput`, captures one authenticated JPEG for `MachineNetworkStillInput`, and uploads with `MachineFileUploadInput`, returning `MachineFileUploadReceipt`. `MachineClock` is the host's time source; `MachineLogEntry` is redacted provider telemetry.

## Session ABI v2

`connect` returns a `MachineSession`. Its reads are `getDescriptor` (`MachineGetDescriptorInput`, returning a `MachineProviderDescriptor` of `MachineInstalledCapabilities`; the host adds revision and incarnation), `getSnapshot` (`MachineGetSnapshotInput`, returning a `MachineReport`) and `observe` (`MachineObserveInput`). The first `MachineObservation` every subscriber receives is a `snapshot`; `changed` deltas follow only after it. Aborting ends the iteration by returning, never by throwing.

`stop` is not a facet: every session has it, and it halts ahead of anything queued. `reconcile` takes `MachineReconcileInput` and reads proof of a late stop, transfer, start or action; it never sends. Both return a `MachineCommandReceipt`: `accepted`, `rejected` with a code, or `unknown`, which the host never retries. `close` and `dispose` release the session.

Four required facets are each `unsupported` or `supported`:

- `actions` is a `MachineActionCapability`. `apply` receives one admitted `MachineProviderActionInput` and sends it once. Before sending, call `checkMachineActionAtSend` with the current report: it repeats state, run, freshness, homing, interlock and availability checks and returns the refusal to report. For an action confirmed by observation, `confirm` reads the most recent report and returns a `MachineActionConfirmation`; for an operation this session never sent, the answer is `pending`.
- `holds` is a `MachineHoldCapability`. `begin` receives `MachineProviderHoldInput` and returns a `MachineProviderHold` whose `extend` sends at most one self-ending segment and whose `release` stops now, or a refusal.
- `jobs` is a `MachineJobCapability`. `completeConfiguration` fills a partial start form (`MachineCompleteConfigurationInput`) from the machine's current setup in the provider's own keys. `prepare` receives `MachineProviderJobInput` and returns a read-only `MachinePreparation`. A `stored` delivery then has `transfer` and `start`; a `streamed` delivery has only `start` (`MachineProviderStartInput`), which returns once the controller takes the first block while the session keeps feeding the rest. Job refusal codes are a `MachineJobFailureCode`: a host code or a provider's own under `MACHINE_JOB_` or `MACHINE_TRANSFER_`, as `isMachineJobFailureCode` checks.
- `stillCapture` is a `MachineStillCaptureCapability`. `capture` takes `MachineCaptureStillInput` and returns a `MachineStill`. Never infer still capture from a network endpoint.
