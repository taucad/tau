## defineMiddleware

`defineMiddleware` returns a `MiddlewarePluginFactory`; calling it yields serializable registration metadata with a private executable definition. Optional hooks are `wrapDescribe`, `wrapEvaluate`, `wrapRender`, and `wrapWrite`. Each receives `(input, next, services)`; `next(input)` continues the chain. Evaluation is independent of any view. Render and write requests name the selected view or export and its declared MIME type; write also carries the extension.

Middleware is assumed to mutate results and therefore participates in cache identity. A pure telemetry/logging tap may declare `mutates: false`; it must return successful results unchanged and declare no dependencies.

A middleware that fulfills framework content declares it by view MIME type or export extension. The bundled edge-detection middleware is one such provider:

```typescript @ts-nocheck
// @ts-nocheck: the docs site does not install `@taucad/middleware`.
import { gltfEdgeDetection } from '@taucad/middleware';

export const gltfEdges = gltfEdgeDetection();
```

The declaration makes a property available only on composed routes where the middleware can run. The runtime projects only the selected MIME or extension's content keys into that hook.

Middleware file inputs are declarative: `entryPath` and dependency `path` values are normalized [runtime paths](../concepts/path-namespaces). The `resolve` hook returns `MiddlewareDependency` values with explicit `affects` operation names. The declaration participates in hashing and, for the current preview, rerender ownership:

```typescript
import { defineMiddleware } from '@taucad/runtime/middleware';

export const settingsFiles = defineMiddleware({
  id: 'settings',
  name: 'settings',
  resolve({ entryPath }) {
    return [{ path: `.tau/settings/${entryPath}.json`, affects: ['evaluate'], watchDebounce: 0 }];
  },
});
```

Middleware does not register watchers imperatively. A missing declaration is retained as an unresolved dependency so creating the file can heal the preview; non-not-found filesystem failures propagate.

Every wrap hook receives a fresh operation-scoped `signal` on `KernelMiddlewareServices`; dependency hooks receive the same primitive on `MiddlewareDependencyServices`. Pass it to cancellable APIs and do not retain it after the hook settles. See [Cooperate with Cancellation](../guides/cooperate-with-cancellation).

## Factories

`@taucad/middleware` exports the `middleware()` toolkit (presets `default`, `cache` and `units`) plus these role factories:

| Factory                   | Purpose                                               |
| ------------------------- | ----------------------------------------------------- |
| `parameterFileResolver()` | Resolve per-file parameter documents beside the entry |
| `parameterUnits()`        | Infer units for parameters without a declared unit    |
| `geometryCache()`         | Cache geometry output by dependency hash              |
| `gltfEdgeDetection()`     | Add requested edge geometry to glTF meshes            |

## Usage

```typescript @ts-nocheck
// @ts-nocheck: the docs site does not install `@taucad/middleware`.
import { createRuntimeClient } from '@taucad/runtime';
import { fromMemoryFs } from '@taucad/runtime/filesystem';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad } from '@taucad/replicad';
import { esbuild } from '@taucad/esbuild';
import { middleware } from '@taucad/middleware';

const runtime = defineRuntime({
  plugins: [replicad(), esbuild(), middleware()],
});

const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromMemoryFs() }),
});
```
