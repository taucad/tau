The shared contract between client and worker runtime: operation results, issues, geometry output, and worker state.

## Result Types

All kernel operations return a discriminated union — check the `success` field to narrow the result:

```typescript
import type { KernelSuccessResult, KernelErrorResult } from '@taucad/runtime';

export type KernelResult<T> = KernelSuccessResult<T> | KernelErrorResult;
```

`KernelIssueType` (`'compilation' | 'runtime' | 'kernel' | 'connection' | 'unknown'`) and `IssueSeverity` (`'error' | 'warning' | 'info'`) classify each issue. `kernelIssueCodeValues` enumerates the stable codes; `isKernelIssueCode` guards one.

## Worker State and Render Phase

`WorkerState` is the worker's current lifecycle state: `'idle'`, `'rendering'`, or `'error'`. Subscribe via `client.on('state', handler)`.

`RenderPhase` identifies the current render phase: `'resolvingDeps'`, `'bundling'`, `'extractingParams'`, `'computingGeometry'`, `'postProcessing'` — subscribe via `client.on('progress', handler)`. `AbortReason` (`'superseded' | 'timeout'`) names why a phase was abandoned.

`Dependency` is the union: `FileDependency | MiddlewareDependency | FrameworkDependency | OptionDependency | ParameterDependency | AssetDependency`.

`FileDependency.path` is a canonical root-relative [runtime path](../concepts/path-namespaces) such as `src/main.ts` — the same spelling used for filesystem calls, cache keys, render identity, change events, and watch ownership. Authority paths and host paths never enter dependency identity.

### Current client bridge

The current client still presents geometry-oriented envelopes until W3's document-view client migration. Those client result types describe the compatibility boundary; kernel authors implement the v2 `evaluate`/`render`/`write` hooks above.

## Usage

The same `KernelResult` shape arrives from `client.export(format, input)` and from `client.on('geometry', handler)`:

```typescript
import { createRuntimeClient } from '@taucad/runtime';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad } from '@taucad/replicad';
import { fromMemoryFs } from '@taucad/runtime/filesystem';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';

const runtime = defineRuntime({ plugins: [replicad()] });
const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromMemoryFs() }),
});
const result = await client.export('glb', {
  source: { files: { 'main.ts': 'export default () => null' } },
});

if (result.success) {
  for (const file of result.data) console.log(file.name, file.bytes.byteLength);
} else {
  console.error(result.issues);
}
```
