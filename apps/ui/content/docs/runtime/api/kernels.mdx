# Kernel Factories

Use kernel factories when registering CAD engines with `defineRuntime`. Each factory returns a `KernelPlugin` that the worker uses for kernel selection and loading.

## Factories

| Factory                 | Extensions | Purpose                                             |
| ----------------------- | ---------- | --------------------------------------------------- |
| `replicad(options?)`    | `ts`, `js` | OpenCASCADE-based parametric BRep via Replicad API  |
| `opencascade(options?)` | `ts`, `js` | Direct OpenCASCADE API access                       |
| `manifold(options?)`    | `ts`, `js` | Mesh-first manifold modeling with robust booleans   |
| `openrscad()` \*        | `scad`     | Rust/Wasm implementation of the OpenSCAD language   |
| `jscad()`               | `ts`, `js` | @jscad/modeling parametric CSG                      |
| `zoo(options)`          | `kcl`      | KCL via Zoo WebSocket API                           |
| `tau()`                 | `*`        | Catch-all converter for STEP, STL, 3MF, OBJ imports |

\* `openrscad()` ships from [`@taucad/openrscad`](https://github.com/matthova/openrscad) (Apache-2.0) and supports browser workers, Node, and the CLI.

## Usage

```typescript
import { createRuntimeClient } from '@taucad/runtime';
import { fromMemoryFs } from '@taucad/runtime/filesystem';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad, opencascade, manifold, jscad, zoo, tau } from '@taucad/runtime/kernels';
import { openrscad } from '@taucad/openrscad';
import { esbuild } from '@taucad/runtime/bundler';

const runtime = defineRuntime({
  kernels: [
    replicad({ withBrepEdges: true }),
    opencascade(),
    manifold(),
    openrscad(),
    jscad(),
    zoo({ baseUrl: 'wss://example.com/v1/kernels/zoo' }),
    tau(),
  ],
  bundlers: [esbuild()],
});

const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromMemoryFs() }),
});
```

## Kernel Entry Paths

Kernel methods receive `entryPath` as a normalized [runtime path](../concepts/path-namespaces) beginning with `/`. It identifies the model's evaluation root inside the filesystem supplied to the runtime, not a host operating-system path. `getDependencies` returns ordinary `path` values in the same namespace.
