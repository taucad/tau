# Choose a Kernel

Choose by source language or import format, then install only the packages your host needs.

| Kernel package        | Input                                     | Best fit                                     |
| --------------------- | ----------------------------------------- | -------------------------------------------- |
| `@taucad/replicad`    | TypeScript/JavaScript using Replicad      | High-level parametric BRep                   |
| `@taucad/opencascade` | TypeScript/JavaScript using OCCT bindings | Direct BRep and topology control             |
| `@taucad/manifold`    | TypeScript/JavaScript using Manifold      | Mesh-first robust booleans                   |
| `@taucad/jscad`       | TypeScript/JavaScript using JSCAD         | CSG modeling                                 |
| `@taucad/openrscad`   | OpenSCAD                                  | `.scad` models in browser or Node            |
| `@taucad/zoo`         | KCL                                       | Configured remote Zoo execution              |
| `@taucad/gltf`        | glTF/GLB                                  | glTF import with sidecars and Draco          |
| `@taucad/brep`        | STEP/STP/IGES/IGS/BREP                    | BRep-family file import                      |
| `@taucad/rhino`       | 3DM                                       | Rhino file import                            |
| `@taucad/assimp`      | Mesh and scene formats                    | OBJ, FBX, STL, PLY, DAE, and related imports |

There is no catch-all Tau kernel. Every first-party import extension has an explicit owner.

## Compose toolkits

```typescript
import { defineRuntime } from '@taucad/runtime/worker';
import { assimp } from '@taucad/assimp';
import { brep } from '@taucad/brep';
import { gltf } from '@taucad/gltf';
import { rhino } from '@taucad/rhino';

export const importRuntime = defineRuntime({
  plugins: [gltf(), brep(), rhino(), assimp({ preset: 'import' })],
});
```

For source-code kernels, include a bundler:

```typescript
import { defineRuntime } from '@taucad/runtime/worker';
import { esbuild } from '@taucad/esbuild';
import { replicad } from '@taucad/replicad';

export const modelingRuntime = defineRuntime({ plugins: [esbuild(), replicad()] });
```

## Configure a packaged capability

Presets select capability sets. Role-nested plugin options configure the factories selected by that preset:

```typescript
import { defineRuntime } from '@taucad/runtime/worker';
import { zoo } from '@taucad/zoo';

export const runtime = defineRuntime({
  plugins: [zoo({ kernels: { default: { baseUrl: 'wss://example.com/v1/kernels/zoo' } } })],
});
```

Use a direct role factory for app-local capabilities, isolated tests, or when a whole role must interleave outside plugin expansion.

Registration order is deterministic. If two kernels deliberately claim the same extension, the first matching registration wins. Duplicate capability IDs fail with diagnostics naming both origins.
