# Use Middleware

Add caching, coordinate transforms, and edge detection to your kernel pipeline. Middleware intercepts kernel operations and transforms results without modifying kernel code.

## Prerequisites

- [Install @taucad/runtime](../getting-started/installation)
- Completed the [Quick Start](../getting-started/quick-start)

## Goal

Configure a runtime client with middleware plugins to cache geometry and parameters, transform glTF coordinates, and add edge detection for sharp-edge rendering.

## Steps

### 1. Import the Middleware Toolkit

First-party middleware is exported from the `@taucad/middleware` toolkit. Use its default preset to install the standard middleware stack:

```typescript
import { middleware } from '@taucad/middleware';
```

### 2. Add Middleware to defineRuntime

Pass the toolkit to `defineRuntime()`. Its preset fixes middleware order; middleware runs in onion-model order (first registered = outermost layer):

```typescript
import { createRuntimeClient } from '@taucad/runtime';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad } from '@taucad/replicad';
import { esbuild } from '@taucad/esbuild';
import { fromMemoryFs } from '@taucad/runtime/filesystem';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';
import { middleware } from '@taucad/middleware';

const runtime = defineRuntime({
  plugins: [replicad(), esbuild(), middleware()],
});

const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromMemoryFs() }),
});
```

Inline `source.files` calls are staged into the transport-owned filesystem. Use `fromMemoryFs()` for ephemeral editor-style source, or wire `inProcessTransport({ runtime, fileSystem: fromNodeFs(...) })` (see step 4) when geometry/parameter caches should persist on disk.

### 3. Understand Each Middleware

**parameterCache()** -- Caches `getParameters` results. Avoids redundant parameter parsing when the same file is analyzed multiple times. Uses the dependency hash as the cache key and stores results under `.tau/cache/parameters/`.

**geometryCache()** -- Caches `createGeometry` results. Skips kernel computation when code and parameters are unchanged. Stores MessagePack-serialized geometry under `.tau/cache/geometry/`. Requires a filesystem that supports writing (e.g., `fromNodeFs`, not `fromMemoryFs` for persistent cache).

**gltfEdgeDetection()** -- Adds edge primitives to glTF meshes for sharp-edge rendering. Improves visual quality when displaying CAD models with hard edges.

### 4. Use a Writable Filesystem for Caching

Geometry and parameter caches require a writable filesystem. Use `fromNodeFs` in Node.js or a writable filesystem in the browser:

```typescript
import { createRuntimeClient } from '@taucad/runtime';
import { fromNodeFs } from '@taucad/runtime/filesystem/node';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad } from '@taucad/replicad';
import { esbuild } from '@taucad/esbuild';
import { middleware } from '@taucad/middleware';

const runtime = defineRuntime({
  plugins: [replicad(), esbuild(), middleware({ preset: 'cache' })],
});

const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromNodeFs('/path/to/project') }),
});
```

With `fromMemoryFs()`, caches are not persisted; geometry and parameter caches will still run but will not survive across sessions.

### 5. Render with Middleware Active

Drive `client.export(...)` as usual. Middleware runs automatically inside the
worker -- nothing changes in the call site:

```typescript
import { createRuntimeClient } from '@taucad/runtime';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad } from '@taucad/replicad';
import { fromMemoryFs } from '@taucad/runtime/filesystem';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';

const runtime = defineRuntime({ plugins: [replicad()] });
const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromMemoryFs() }),
});

const result = await client.export('glb', {
  source: {
    files: {
      'main.ts': `
      import { drawRoundedRectangle } from 'replicad';
      export default function main() {
        return drawRoundedRectangle(30, 50, 5).sketchOnPlane('XY').extrude(10);
      }
    `,
    },
  },
});

if (result.success) {
  for (const file of result.data) {
    console.log(`Exported ${file.name}: ${file.bytes.byteLength} bytes`);
  }
}
```

For UI viewers driving the autonomous render loop, see [Live Rendering](./live-rendering) -- middleware applies identically there.

## Variations

- **Toolkit composition**: Use the middleware toolkit's default preset when all four first-party middleware roles are wanted:

```typescript
import { createRuntimeClient } from '@taucad/runtime';
import { defineRuntime } from '@taucad/runtime/worker';
import { replicad } from '@taucad/replicad';
import { middleware } from '@taucad/middleware';
import { fromNodeFs } from '@taucad/runtime/filesystem/node';
import { inProcessTransport } from '@taucad/runtime/transport/in-process';

const runtime = defineRuntime({ plugins: [replicad(), middleware()] });
const client = createRuntimeClient({
  transport: inProcessTransport({ runtime, fileSystem: fromNodeFs('/path/to/project') }),
});
```

- **Selective middleware**: Omit middleware you do not need. For example, skip `gltfEdgeDetection()` if your viewer does not use edge rendering.
- **Middleware order**: Place caches (parameterCache, geometryCache) before `gltfEdgeDetection` so cached results still flow through edge generation on the return path.
