# Sensor Shell

Printed enclosure for the launch `tscircuit/usb-sensor-breakout` board (42 mm × 26 mm × 1.6 mm). The cavity is that outline plus `clearance` on each side.

Replicad is the showcase because the wall, the rounded plan and the lid plug are one exact solid. A mesh boolean can print a similar box; it cannot hand the same body to a CNC post as STEP with the fillet still a fillet.

The lid is parked behind the shell so the fixed thumbnail camera shows both pieces. Parameters: `clearance`, `wall`, `floor`, `cavityHeight`, `cornerRadius`, `edgeRadius`, `usbWidth`, `usbHeight`, `lidThickness`.
