# Worm and wheel — tooth manufacturing definition

Status: geometry preparation for a matched custom gearset. Working process assumption: machined steel worm and hobbed bronze wheel. This is not a production release or a rated gearbox. Input speed, output torque, duty cycle, material grades, heat treatment, lubricant and the actual hob/tooling have not been supplied.

Assembly reference: 40.000 centre distance, 90° shaft angle, no profile shift. Wheel mid-face intersects the worm axis plane. Nominal circumferential backlash at the wheel reference circle is 0.160, equivalent to 0.305577° of unloaded wheel play. Backlash is cut into the wheel tooth space; the worm retains its nominal reference tooth thickness.

The wheel blank throat is an R8.000 circular arc centred at radial coordinate 40.000 in a meridian section. It meets the Ø66 outer cylinder at axial offsets ±3.872983. This is a turned concave blank followed by generated tooth spaces, not a twisted spur gear.

## Generating tool and machining route

The ideal generating hob has the same 20.000 reference diameter, 6.283185307 lead, right-hand single start and 20° **axial** flank form as the worm. Its tip diameter is 25.000, providing 0.500 radial clearance below the working worm tip. Its axial reference tooth thickness is 3.301592654, adding the wheel's 0.160 backlash, and its tip corners have R0.400. This is a continuous ideal generating surface, not a finished relieved and gashed hob drawing.

1. Agree the worm form and the actual hob cutting-edge geometry with the gear shop before ordering tooling. A nominal module and pressure angle alone do not define an interchangeable worm gearset. A 20° normal-angle hob is not the specified 20° axial-angle hob.
2. Turn the worm blank and journals about one datum axis. Machine the right-hand ZA groove with the defined lead, straight axial flanks and R0.300 tool nose. The CAD cutter can be inspected using `component: 'worm-cutter'`. The 0.150 crest breaks must stay above the working flanks; preserve the 50 mm overall thread envelope and end tapers.
3. Turn the wheel bore, hub, faces and throat about the wheel datum axis. Hob at the stated generating centre distance with synchronized 1:30 rotation, centred on the wheel mid-face. The selected tool must reproduce the specified reference thickness and extended, rounded tip.
4. Deburr tooth ends without rounding the working flanks. If hardening or finish grinding is required, establish stock allowance and a finishing method that preserves the ZA axial form before rough cutting.
5. Inspect the matched pair at the specified centre distance and shaft alignment, then check backlash, marking pattern and free rotation through a complete wheel revolution in both directions. Final acceptance must include the agreed operating load and temperature.

No pitch-diameter oversize, crowning, lead correction or intentional contact localization is included. A shop using an oversize hob must regenerate and assess the resulting pair; simply substituting its cutter is not covered by this geometry.

## Geometry definition and checks

`tooth-profile.ts` defines the generating envelope from the screw equation and the zero normal-relative-velocity condition. The rounded generating-tool tip is included in that envelope. `main.ts` fits the resulting curves into BRep tooth-space lofts, patterns one space around the wheel, and cuts them from the analytical turned blank. The analytic definition and the agreed hob are the manufacturing master; CAD spline fitting tolerance is not a machining tolerance.

Run the independent analytical check with:

```sh
node tooth-profile.test.ts
```

The GeoSpec suite checks valid closed solids, dimensions, bores and mounting features, separate components, assembly interference, sampled synchronized gear positions, and a 32-tooth wheel variant. The `verifyProfiles` test also checks off-grid analytical working-flank points against the CAD surfaces with a 0.005 mm limit. Sampled clearance and surface-distance checks are not a loaded tooth-contact analysis or a proof over every point and every rotation angle.

Verification completed: all 19 GeoSpec cases passed across smaller runs, including eight input phases from 0° through 315° and 408 analytical-to-CAD surface samples. The independent screw/envelope residual check also passed. A single combined GeoSpec run encountered a Tau native/WASM cleanup error after the first ten passing cases; the remaining cases passed when filtered into smaller batches. If that runner issue recurs, use test-name filters for groups of two or three mesh positions. Compilation and the isometric visual inspection passed.

The support frame, bearing fits, axial-thrust restraint, wheel-to-shaft torque connection and shaft/coupling interfaces retain their concept dimensions and are outside this tooth-profile release. In particular, the Ø12.3 wheel bore and Ø12 shaft are not a completed keyed manufacturing fit. Resolve these interfaces before manufacturing the complete assembly.
