# Vented Panel

A 120 mm × 72 mm plate, corner-filleted, with a 5 × 3 grid of 8 mm holes. Change `columns`, `rows` and `holePitch` and the same file is a rack panel instead of a sample.

Zoo KCL is the showcase because the hole count is a `patternTransform` on a cloud GPU engine. The product copy for this kernel is large assemblies that stall a WASM tab. A browser OpenCascade session can fillet this modest plate; it is the pattern, not the rectangle, that wants the server. Manifold would boolean the holes faster as mesh and would not return STEP with the corner fillets intact.

**Run status: unverified.** Zoo is not composed in `exampleRuntime` or `workspaceRuntime`, and evaluating KCL needs a Pro session. There is no thumbnail.

The catalog id is `zoo`. The file is `main.kcl` at KCL 3.0, millimetres.
