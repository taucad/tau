## Existing runners

Native Node and Node/WASM runners accept private `--suite material`; their default remains the original 320 corpus. The existing browser runner accepts `--suite material` and uses its same packed public root in Chromium, Firefox and WebKit. Python exposes separate `test_material_v6_byte_facade` cases and the existing script's `--material` selection. Rust runs `material_v6_portable_controls_bind_independent_inputs_and_full_cold_warm_results` in `mesh_conformance`.

These source controls are not a product qualification, a multi-threading qualification, a hard process-memory cap, general CAD validity or a release claim. Self-intersection controls remain separately qualified by existing core tests, not claimed as coverage of this portable suite.
