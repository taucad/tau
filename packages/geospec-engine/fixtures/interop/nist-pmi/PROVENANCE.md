# NIST PMI STEP AP242 Interop Corpus — Provenance

Third-party-authored STEP files for AP242 GD&T/datum interoperability testing. Unlike the
generated fixture families (`contact/`, `mate/`, …), these files are **pristine upstream
artifacts — never edit or regenerate them**. They are the ground truth for what
standards-conformant CAD systems actually write.

## Source

- Publisher: NIST — MBE PMI Validation and Conformance Testing Project
  (<https://www.nist.gov/ctl/smart-connected-systems-division/smart-connected-manufacturing-systems-group/mbe-pmi-validation>)
- Archive: `NIST-PMI-STEP-Files.zip`, retrieved 2026-07-12 from
  <https://www.nist.gov/document/nist-pmi-step-files>
  (redirects to `https://www.nist.gov/system/files/documents/noindex/2024/06/19/NIST-PMI-STEP-Files.zip`)
- Archive SHA-256: `8fa78429e6d8d9b0d7681d223b6aa9ec98c3772185c55b1a0e3679b21c181911`
- Files below are byte-identical extractions from that archive (per-file SHA-256 recorded).

## License

NIST download page, verbatim: _"The test cases, CAD models, and STEP files can be used
without any restrictions. Their use in other software or hardware products does not imply
a recommendation or endorsement of those products by NIST."_ NIST asks for
acknowledgement (this file) and prohibits use of the NIST logo in promotional materials.
US-government works are not subject to US copyright (17 U.S.C. §105). Long-term
redistribution in this repository is therefore safe.

Note: NIST deliberately removed information identifying which CAD system generated each
file ("Information that shows which CAD software generated the files has been removed" —
archive README). The files were "generated by different CAD software"; header styles
confirm at least six distinct STEP processors across the set. Per-system attribution is
only available in the CAx-IF/MBx-IF member area, which is **not** redistributable — do
not add files from there.

These files are NOT syntax-error-free reference files (per the NIST README) — that is a
feature: a robust reader must tolerate them.
