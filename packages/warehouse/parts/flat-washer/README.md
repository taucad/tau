# Flat washer

Flat washer; one M3/M4/M5/M6/M8/M10 diameter selects all admitted head, socket or washer dimensions.

Supplier-table dimensions: Fastenal ISO 4762 REV-03 (head max, socket min); Fuller DIN 933 nominal hex head; Aspen hex nut table max; Woodstock DIN 125A washer nominal. Threads are symbolic nominal cylinders. Chamfer/relief detail is illustrative; no complete standards or material certification.

All dimensions are millimetres. Edit main.ts and its local model.ts or use Tau parameters. Domains and qualified combinations are in parameters.ts. Defaults and every declared domain boundary/discrete value are tested by main.geospec.ts through STEP and GLB. These finite checks do not prove every intermediate real-valued combination.
